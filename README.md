# 🧹 CleanSheet AI

> Clean your Excel files in seconds — remove duplicates, empty rows, empty columns, trim spaces, merge/split columns, sort data, and download a clean spreadsheet instantly.

---

## ✨ Overview

CleanSheet AI is a modern Excel data cleaning application built with **Next.js**, **TypeScript**, and **React**.

It helps users clean messy spreadsheets without writing formulas or using complex Excel tools.

The project demonstrates:

- Modern React architecture
- TypeScript development
- File processing
- Automated testing with Vitest
- Continuous Integration using GitHub Actions
- Clean component-based design

---

## 🚀 Features

### Excel Processing

- Upload Excel (.xlsx, .xls)
- Preview spreadsheet
- Download cleaned Excel

### Cleaning Tools

- Remove Duplicate Rows
- Remove Empty Rows
- Remove Empty Columns
- Trim Extra Spaces
- Find & Replace
- Sort Data
- Split Columns
- Merge Columns
- Auto Clean

### Engineering

- TypeScript
- Component Architecture
- Utility Layer
- Unit Testing
- GitHub Actions CI
- Responsive UI
